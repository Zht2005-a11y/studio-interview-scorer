# 工作室面试打分系统

手机浏览器打开，面试官点选等级即可打分，自动统计每位面试者的平均分排名。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `server.js` | 服务端。含**初始名单**（只在首次启动时用一次） |
| `public/index.html` | 手机页面（打分 + 排名 + 管理） |
| `data/config.json` | 组、面试官、面试者名单，首次启动自动生成，**之后在 App 里改** |
| `data/scores.json` | 打分数据，自动生成，别删 |

## 一、启动

需要装 Node.js（18 以上），无需 `npm install`。

```bash
node server.js
# 换端口：PORT=8080 node server.js
```

启动后控制台会打印访问地址，手机浏览器打开 `http://服务器IP:端口/`。

## 二、维护名单

**不用改代码**。手机页面右上角齿轮 → 「管理名单」：

- 切换组
- 「面试官」输入框加名字，点名字后面的 `×` 移除
- 「面试者」同理

> 移除面试者或面试官时，会**连带删除该人的打分记录**，会有二次确认。

`server.js` 顶部的 `SEED` 只是初始名单，只在 `data/config.json` 不存在时生效。想彻底重置名单：删掉 `data/config.json` 重启。

## 三、面试官怎么用

1. 选自己所在的组 → 选自己的名字（只需选一次，之后自动记住）
2. 点面试者 → 选「表达能力」和「是否常来工作室」两个等级 → 保存
3. 保存后自动跳到下一位未打分的面试者

也可以直接把带参数的链接发给对应面试官，打开即自动进入：

```
http://服务器IP:端口/?g=g2&n=申宇轩
```

组 id 分别是 `g1` `g2` `g3` `g4`。

## 四、看排名

底部切到「排名」标签：

- 平均分 = 本组所有面试官给他的（表达分 + 意愿分）之和 ÷ 已打分面试官人数
- 分数并列共享名次，未打分的排在最后
- 点某一行展开看每位面试官的具体打分

## 五、评分标准

| 维度 | 等级 | 分数 |
| --- | --- | --- |
| 表达能力 | 偏弱 / 良好 / 优秀 | 60 / 75 / 90 |
| 是否常来工作室 | 意愿弱 / 意愿一般 / 意愿强 | 65 / 80 / 90 |

两项直接相加，满分 180。

## 六、注意事项

- 多人同时打分没问题，同一人对同一面试者重复提交会**覆盖**旧分，不会重复计算
- 想清空所有打分：停服务，删 `data/scores.json`，再启动（名单保留）
- 正式放到公网建议用 Nginx 加 HTTPS 反代；系统本身支持子路径部署（如 `http://ip/interview/`）
