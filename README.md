# 工作室面试打分系统

手机浏览器打开，面试官点选等级即可打分，自动统计每位面试者的平均分排名。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `server.js` | 服务端。含**初始名单**（只在首次启动时用一次） |
| `public/index.html` | 面试官页面（打分 + 排名 + 管理），网址 `/` |
| `public/apply.html` | **面试者答题页**（只有选择题作答），网址 `/apply` |
| `data/config.json` | 组、面试官、面试者、轮次、打分项（含每轮考察范围），首次启动自动生成，**之后在 App 里改** |
| `data/scores.json` | 打分数据，自动生成，别删 |
| `data/paper.json` | 题库（全局一份，不分轮次），自动生成，别删 |
| `data/answers.json` | 面试者的抽题与作答记录，自动生成，别删 |

## 一、启动

需要装 Node.js（18 以上），无需 `npm install`。

```bash
node server.js
# 换端口：PORT=8080 node server.js
```

启动后控制台会打印访问地址，手机浏览器打开 `http://服务器IP:端口/`。

## 二、维护名单

**不用改代码**。手机页面右上角齿轮 → 「管理名单」：

- 切换组
- 「面试官」输入框加名字，点名字后面的 `×` 移除
- 「面试者」同理

> 移除面试者或面试官时，会**连带删除该人的打分记录**，会有二次确认。

`server.js` 顶部的 `SEED` 只是初始名单，只在 `data/config.json` 不存在时生效。想彻底重置名单：删掉 `data/config.json` 重启。

组、轮次、打分项也都在「管理」页里维护（底部导航第三个标签）。

## 三、配置每轮考察的打分项

各轮考察的范围**完全由你自己决定**，系统不做任何自动关联。手机页面「管理 → 轮次」里，每个轮次一行，点进去勾选：

- 来源是「管理 → 打分项」里已经建好的项，点一下开关立即生效，不用保存
- 配置时发现缺一项？面板里有 **「＋ 新建打分项」**，就地建一个，建好会自动勾到这一轮（其它轮次不受影响）
- **在别处新加的打分项不会自动进入任何轮次**，要在这里手动勾上
- 想勾几项就勾几项，也可以全部取消（那样这一轮打不了分，界面会提示去配置）
- 取消勾选某项后，该项的分数**不再计入这一轮的合计与排名**（历史记录还在，重新勾上就恢复）
- 新建轮次时也不会预置任何打分项，添加完会直接打开配置面板让你挑

改动的影响：

| 位置 | 表现 |
| --- | --- |
| 打分页 | 只显示本轮勾选的项；顶部有轮次切换条和「本轮考察」提示（没配置会橙色提示 + 「去配置」按钮） |
| 排名页 | 平均分只按本轮勾选的项计算；各轮范围不同时，跨轮总排名会给出提示 |
| 打分项管理 | 每个打分项下面会标出它被哪些轮次考察，没被任何轮次勾选会明确写出来 |

> 删除某个打分项时，它会自动从所有轮次的勾选里移除，不会自动补上别的项。

## 四、面试官怎么用

1. 选自己所在的组 → 选自己的名字（只需选一次，之后自动记住）
2. 顶部轮次条切到当前这一轮（各轮考察项不同，注意别选错）
3. 点面试者 → 逐项选等级 → 保存
4. 保存后自动跳到下一位未打分的面试者

也可以直接把带参数的链接发给对应面试官，打开即自动进入：

```
http://服务器IP:端口/?g=g2&n=申宇轩
```

组 id 分别是 `g1` `g2` `g3` `g4`。

## 五、看排名

底部切到「排名」标签：

- 平均分 = 本组所有面试官给他的（本轮各项分数之和）÷ 已打分面试官人数
- 分数并列共享名次，未打分的排在最后
- 点某一行展开看每位面试官的具体打分

## 六、评分标准

| 维度 | 类型 | 等级 / 范围 | 分数 |
| --- | --- | --- | --- |
| 表达能力 | 选等级 | 偏弱 / 良好 / 优秀 | 60 / 75 / 90 |
| 是否常来工作室 | 选等级 | 意愿弱 / 意愿一般 / 意愿强 | 65 / 80 / 90 |

两项直接相加，满分 180。

### 打分项有两种类型

新建打分项时（「管理 → 打分项 → ＋ 新建打分项」）可以选：

- **选等级 · 分值固定** —— 每个等级一个固定分值，面试官选一个（就是上表这两个）
- **自由填分** —— 不设等级，只要填个名称和满分（默认 100），**面试官打分时自己填 0 ~ 满分之间的分数**

自由填分型适合「综合印象」「技术深度」这类不好用固定档位描述的项。两种类型可以混用，每轮考察哪几项也照常自由勾选。

打分项建好后还能改类型：**选等级 → 自由填分**会把原来的等级按各自分值换算成自由分（不丢分）；**自由填分 → 选等级**没法换算，会清掉这一项的历史分数（保存前会有提示）。

> 还有第三种 **「自动计分」** 型：分数由系统按面试者的作答记录实时算，面试官不填也改不了。
> 目前系统内置的「答题得分」就是这种（见第八节）。它由系统自动创建，新建打分项时不会出现在选项里。

## 七、注意事项

- 多人同时打分没问题，同一人对同一面试者重复提交会**覆盖**旧分，不会重复计算
- 想清空所有打分：停服务，删 `data/scores.json`，再启动（名单保留）
- 正式放到公网建议用 Nginx 加 HTTPS 反代；系统本身支持子路径部署（如 `http://ip/interview/`）

## 八、面试者答题（网址 `/apply`）

面试者和面试官用**两个不同的网址**，页面也是两个独立文件 —— 面试者打开的页面里**根本没有**打分、排名、管理的入口和代码。

| 谁 | 网址 |
| --- | --- |
| 面试官 | `http://服务器IP:端口/` |
| 面试者 | `http://服务器IP:端口/apply` |

面试官现场把这个网址做成二维码贴出来即可。

### 题库与随机抽题

题库是**全局一份**，不分轮次。「管理 → 题目」里维护，两种题型：

- **选择题**：题面 + 若干选项，勾上左边的方框 = 正确答案；可选单选 / 多选。**每题固定 5 分**，系统按正确答案自动判分（多选要全部选对才得分）
- **编程题**：只有题面。**每题固定 10 分**，面试者用 VS Code 写，由面试官人工填分

**每位面试者进来答题时，系统会从题库里随机抽 3 道选择题 + 2 道编程题**。所以题库**至少要备 3 道选择题 + 2 道编程题**，页面会实时提示够不够（建议多备一些，抽到的组合才不会太重复）。抽到之后**固定不变** —— 刷新页面、换设备重进，看到的还是同一套题。

### 面试者怎么用

1. 打开 `/apply`，在名单里搜自己的名字点一下（选过之后这台电脑会记住）
2. 逐题作答：**选择题点选项**，**编程题只看题面**（用 VS Code 写，不在系统里提交）
3. 点底部「提交」。提交后可以「重新作答」，重复提交会**覆盖**上一次的答案

> 面试者**看不到自己的分数**（防泄题）。想看的话可以改 `apply.html` 里的成功页。

### 得分怎么算

| 部分 | 满分 | 谁给分 |
| --- | --- | --- |
| 选择题 3 道 × 5 分 | 15 | 系统按正确答案**自动判分** |
| 编程题 2 道 × 10 分 | 20 | **面试官人工填**（每题 0~10） |
| 合计 | 35 | —— |

### 面试官在哪看、在哪给分

1. 打分页的面试者卡片上会显示「笔试 选择 15/15 · 编程 7/20」
2. 点进某人的打分弹窗，顶部有「笔试作答」区块：
   - 一行汇总：`选择 15/15 + 编程 7/20 = 22/35`
   - **编程题下面直接有打分框**，每题填 0~10，填完立刻保存
   - 点「展开选择题明细」能看到他每题选了什么、正确答案是什么、对错

### 内置的「答题得分」打分项（自动计分型）

系统内置了一个打分项（默认名 **「答题得分」**，**自动挂到第 2 轮**），类型是 **「自动计分」**：

- **分数由系统实时算出来 = 选择题自动判分 + 编程题面试官人工分**，面试官**不用填、也填不了**（弹窗里是只读的）
- 它照样参与排名：**第 2 轮排名 = 面试官打分的平均分 + 答题得分**；「全部（总）」排名里也含它
- **只交了卷、还没被任何面试官打分的人，也会出现在排名里** —— 分数就是答题得分（不再只显示"还没有面试官打分"）
- 一切都是**读取时实时计算**：面试官给编程题打完分、或者你改了题目的正确答案，排名**立刻**跟着变
- 改名字：去「管理 → 打分项」点铅笔（自动项只能改名，不能改成别的类型）
- 想挪到别的轮次：去「管理 → 轮次」里勾选（和普通打分项一样自由）

> ⚠️ **升级说明**：老版本这个打分项是「自由填分」型、由面试官手填。升级后**第一次启动会自动把它转成自动计分**，
> 并把它从「第 2 轮以外」的考察范围里摘掉。这是**一次性**迁移 —— 之后你在界面里怎么改都不会被覆盖。
> 如果你更希望答题分只算选择题、或者只算编程题，目前需要在 `data/config.json` 里把该项的
> `source` 改成 `"choice"` / `"code"`（默认 `"answer"` = 两者之和）。

### 几个要点

- 至少 2 个选项、必须有 1 个正确答案，否则保存会被拒绝；单选时勾多个会自动收敛成一个
- **改了正确答案，历史作答的得分会自动重算**（作答只记录"选了什么"，分数是实时算的）
- 删除题目会**连带把它从所有人的抽题记录里移除**（那个人会少一道题）
- 题库不够抽时，答题页会提示面试官补题
